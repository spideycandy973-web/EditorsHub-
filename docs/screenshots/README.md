Captured from the web/PWA editor with headless Chromium at 390×844 (mobile) and 1280×800 (desktop).

- `editor-add-v2.3.0.png` — Add menu: six AM categories, All/Browse filter rail, labelled right

  dropdown, left keyframe rail and right quick-action rail.

- `editor-desktop-v2.3.0.png` — desktop editor with the inspector docked right.
