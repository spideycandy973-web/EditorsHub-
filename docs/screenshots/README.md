# EditorsHub v3.0.0 UI screenshots

Captured headlessly at 430 × 900 (the same phone viewport used by the reference screenshots).
The v2.x screenshots below are kept for history; **v3.0.0 is the current UI**.

## v3.0.0 — dark studio rebuild

- `home-v3.0.0.png` — black launcher: wordmark, gear/avatar, Upload XML card, Import Project
  Package card with URL field, lavender Import and teal Scan QR image, pill bottom nav.
- `settings-v3.0.0.png` — Settings sheet: Low Quality Preview, Show Off Timeline, Remember Add
  page, Default Layer Duration, Audio Resampling, website / downloads / share / About rows.
- `create-v3.0.0.png` — Project / Element create sheet with ratio chips, resolution, frame rate,
  background and lavender Create Project.
- `editor-v3.0.0.png` — black 9:16 stage, transport, ruler, right zoom toolbar, teal FAB.
- `add-v3.0.0.png` — Add grid: Media / Text / Shape / Audio / Freehand Drawing / Vector Drawing /
  Element Project / Template / Camera / Null / Empty Group.
- `shapes-v3.0.0.png` — three-page 18-shape picker with real canvas silhouettes.
- `properties-v3.0.0.png` — selected-layer contextual top bar and the eight property tiles.
- `move-v3.0.0.png` — Move & Transform with X/Y fields, XY pad, left/right rails and timeline.
- `rotation-v3.0.0.png` — rotation dial view.
- `easing-v3.0.0.png` — cubic-bezier easing graph with real draggable control points.
- `effects-v3.0.0.png` — effects browser with 20 real effects.
